# SkyWalk FoodCourt — React + Vite

A responsive restaurant/food-court website for SkyWalk FoodCourt, Uppal, Hyderabad.

## Included
- React + Vite frontend
- Responsive mobile/tablet/laptop layout
- 5-section sticky navigation: Home, Menu, About, Reviews, Visit Us
- Framer Motion scroll/reveal animations
- Local food + storefront images supplied by the client
- No food prices displayed
- Phone, email and Google Maps direction links
- Netlify-ready `netlify.toml`

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The deploy folder is `dist`.

## Netlify
You can upload this project to a Git repository and connect it to Netlify. The included `netlify.toml` configures the build command and SPA fallback automatically.
